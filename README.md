本人曾就此向学院提出质疑。**据本人回忆，学院相关老师以研究方向相同、出现巧合在所难免作出解释，但未向本人提供能够具体说明这些选题重合情况的核查过程或实质性答复**。本人难以仅凭这一解释消除疑虑，希望学院能够认真核查选题来源、形成时间和材料接触情况，并明确如何保护学生的课程论文与研究成果。

### 关于追问项目创新点来源时遭遇心理标签化回应（2026年10月29日补记）

据本人回忆，在我就部分学生研创项目及其他科研项目与本人课程论文中具体创新点的重合问题提出质疑，追问是否存在抄袭或不当使用、并希望了解相关创新点的来源和形成时间时，相关沟通人员还以“精神和心理有问题”之类的说法评价我。**上述内容系本人对沟通经历的转述，具体原话、发生时间、说话对象及原始记录仍待进一步核对和补充；创新点出现重合本身也不等于已经证实抄袭，我要求的是基于证据的核查。**

**这简直是对正常学术质疑的荒唐回应。** 学生问的是项目原创性、创新点来源与研究材料的时间线，理应得到事实、材料和具体解释。**拿对提问者精神或心理状态的评价来转移话题，是用人身标签代替学术论证、用主观贬损回避客观核查。** 即便对我的判断不同意，也完全可以拿出项目申报书、研究过程记录、原始文档和形成时间来说明；何必把一个可以检验的学术问题，扯成对学生个人状态的评判？**对质疑者贴标签，既不能证明项目没有问题，也不能让创新点来源的问题自行消失。**

**我追问的是创新点从何而来，不是在请求任何人替我做精神或心理诊断。** 是否存在抄袭、不当借鉴或独立形成，应由具体证据决定，而不是由谁说话更有权威、谁能给对方扣上什么帽子决定。请正面说明：相关创新点何时提出、如何形成，有哪些可供核验的原始材料，相关人员是否接触过我的课程论文及研究内容？如果不存在不当使用，就请以材料和时间线作出解释；如果沟通中确有以精神或心理问题否定提问者的表达，也应正视并纠正这种不尊重人的处理方式。**学术争议应以证据回应，不能靠羞辱和污名化让提问者闭嘴。**

**现阶段暂不公开涉及的教师和学生姓名**。我希望学院给出明确调查结果，而不是用研究方向相同、巧合难免来结束沟通。相关课程论文、研创项目材料及沟通记录将继续保存。

结合此前课程考试、课程论文选题重合以及奖学金成果认定等经历，**我感到自己在科研投入和奖学金评审中反复受到不公平对待，付出被不断消耗，甚至有被压榨的感受，奖学金机会也一次次受到影响**。

**2025年，我认为课程考试严重超纲，并因此错失当年各类奖学金；2026年虽然最终拿到了国家奖学金，采用的却还是2025年的竞赛奖项，其他申报奖项没有获得认定。** 这才是我最不满的地方：**评出一个国奖，无法自动证明成果认定的每一步都公平透明。** 请公开具体规则和逐项计分依据，别让学生靠猜测判断该投入什么成果。

**关于学院领导与2025年奖学金事件的疑问（2026年10月16日补记）**：在新沟通中，对方称相关情况已同步给“领导”。据本人说明，这里指的是**学院领导**；对方另外确认提到的“研工部”是**学校研工部**。结合我在2025年遇到的课程考核和奖学金评审问题，**我怀疑相关学院领导是否也参与、知悉或影响去年的奖学金事务，希望查明其实际职责及参与情况**。这是一项需要核查的疑问，现有截图不能证明对方与去年的不公平结果有直接关联。

## 十、最后总结

**我最终决定不再申请博士，不是因为不愿继续做科研，而是害怕在博士阶段重蹈覆辙，再次经历类似的不公平对待，让自己受到新的伤害。** 这种恐惧不是由某一件事造成的。2025年，我认为张宏武老师相关课程的期末考试严重超出硕士课程学习范围，影响了我的成绩与绩点，并使我未能获得后续各类奖学金。此外，我的课程论文研究主题多次与学院其他学生的研创项目出现重合；我还注意到，部分老师发表的论文，以及其申请或已经获批的国家基金项目，与我论文中的部分研究内容或具体创新点存在重合。这些问题至今没有得到令我信服的核查与解释。接连发生的事情让我担心，即使继续投入数年时间和精力读博，也可能再次遭遇同样的困境：付出了科研劳动，成果和权益却未能得到公正对待，提出质疑后也难以获得明确回应。

**尤其让我难以释怀的是研究内容和具体创新点重合的问题。** 我所质疑的并不只是研究方向相近，还包括部分具体研究问题、创新点以及相关成果出现的时间关系；据我所知，其中涉及的部分国家基金项目已经获批立项。此前学院曾以“研究方向相同，难免出现重合”作出解释，但我认为，这不足以直接解释具体创新点为何重合。

到了2026年，我的论文已于7月在出版社官网正式在线发表，并于7月23日形成 `Version of Record`，却在10月12日才被明确告知不能计入当年的奖学金评审，理由是图书馆或WOS检索报告记载的出版日期更晚。**最终，2026年度国家奖学金我是拿到了，但真正被认定、最终用来拿下国奖的，居然还是2025年的竞赛奖项；本次申报的其余奖项全部不予认定，2026年7月已正式在线发表的论文也没有按本人主张计分。** **这结果看似是在弥补我2025年未能拿到国奖的遗憾，可到头来支撑这次获奖的还是2025年的竞赛，其余申报成果却依旧被挡在认定之外。** 我说的是这种结果带给我的感受，并非断言学院存在已查实的“补偿安排”。**如果获奖只能靠去年那份竞赛成绩撑起来，今年实实在在提交的其他成果又为何被一笔划掉？看似给了一个交代，却没有回答任何一项具体成果为什么不算。** 辛辛苦苦做出的成果摆在那里，评审时却只剩去年的竞赛能算——**这不是一句“反正国奖你已经拿到了”就能轻轻带过的事。**

**我就想问：2025年的竞赛可以认，为什么其余申报奖项一概不认？2026年7月就已经发布正式版本的论文，为什么要等到评奖时才用另一个出版日期把它排除？** 哪一项不符合条件、不符合哪一条、条款是什么时候发布的、适用于哪一类奖学金，请逐项写清楚、拿出原文和审核记录。**有规则就亮规则，有依据就摆依据；不要拿“以前一直如此”代替成文规定，更不要拿一个已经发下来的国奖当挡箭牌，以为其他成果的认定争议就可以一笔勾销。** 据本人目前核对的已公开文件，我尚未见到截至2026年8月31日已经正式公布、并明确要求以检索报告相应日期作为本次硕士生奖学金论文唯一发表日期的条款；如学院认为存在，请直接出示并说明适用依据。

**更荒唐的是，当我追问规则何时公开、为何论文不能计分时，得到的沟通内容里还有“退群”“任性”以及漏收通知责任自负的提醒。** 请先回答：论文日期的限制有没有在8月31日前按规定公布？在哪里公布？适用哪些硕士奖学金？如果连这几个问题都没有白纸黑字的答复，**把焦点转向学生是否在班群、是否够“懂事”，只会让规则公开的核心问题被转移。**

**评奖评的究竟是学生实实在在做出的成果，还是谁能提前猜中一句没有明确公开的认定口径？** 我不是要求任何奖项无条件加分，也不是因为没拿到国奖才来申诉。**我已经拿到国奖，恰恰更要追问：为什么今年提交的其他奖项统统被否？为什么已经正式发表的论文不能计分？** “不认定”三个字可以轻飘飘地说出口，但学生付出的时间、错过的机会和承担的后果，不会因此消失。**一句“不算”不是解释，一句“按惯例”不是条款，一张国奖证书更不是免于接受质疑的通行证。**

我要求学院**逐项公开本次申报奖项的认定结果、具体理由、适用文件及其公布日期、本人计分记录和复核渠道**，并重新核查2026年7月正式发表论文的计分资格；如确有错误，应当依规更正。同时，请对2025年课程考核与奖学金影响、研究内容重合等争议给出有事实依据的答复。**我尊重其他学生获得奖学金的权利，但也要求自己的成果得到有章可循、经得起核查的评价。**

我最终不再申请博士，不是畏惧科研本身，而是不愿未来再花几年时间重复经历这种投入与认定脱节、规则难以核验、追问得不到明确答复的消耗。**一个公平的评审，不应该只敢公布谁拿了奖，却不敢说明谁的成果为什么不算。**
